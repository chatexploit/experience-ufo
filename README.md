# Experience UFO

Standalone static website for GitHub Pages.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and `.nojekyll`.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the Pages URL.

The site is self-contained: the UFO artwork is embedded in `index.html`, so no separate image upload is required.
